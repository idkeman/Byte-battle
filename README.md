# Byte Battle

A browser-based real-time strategy game built with plain HTML, CSS, and JavaScript. No build step, dependencies, or downloads are needed.

## Play
Open [Byte Battle on GitHub Pages](https://idkeman.github.io/Byte-battle/) after enabling Pages in the repository settings (Deploy from branch: `main`, folder: `/ (root)`).

## Features
- Passive **Bytes** currency, plus upgradeable income generation.
- Deploy Scouts, Tanks, and Snipers with different speed, health, range, and damage.
- Protect your blue core while attacking the red AI core.
- Reinforce your base, choose AI difficulty, and toggle allied team support.
- Responsive layout and canvas battlefield.

## Controls
Click **Start battle**, select a unit, then click **Deploy**. Buy upgrades with Bytes while the match is running. Reset starts a fresh match.

## Files
- `index.html` — game UI
- `style.css` — responsive dark interface
- `game.js` — simulation, AI, combat, currency, and drawing

Progress is currently session-only and resets when the page is refreshed.
